## Espacio de presentación del proyecto

Este portal comparte documentación y entregables del futuro sistema de gestión del portafolio de aplicaciones con IA agéntica.

**Estado:** entorno documental inicial. El sistema funcional aún no está implementado.

- [Arquitectura del sistema](/arquitectura/): modelo ArchiMate del APM (catálogos, IA agéntica, roadmap).
- [Documentos PDF](/documentos/): consulta y descarga los archivos publicados.
- [Guía de publicación](/guias/publicacion/): cómo compartir nuevas versiones.

La documentación evoluciona en paralelo a la construcción del sistema. Cada despliegue exitoso publica una nueva versión del contenido.
